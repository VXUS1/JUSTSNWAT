PARA-E. Pipeline conventions:
Refer to standard 5-stage MIPS pipeline:
• V1 = RegWrite signal (entering ID stage / Register file write)
• V2 = RegDst mux control (EX stage)
• V3 = MemtoReg mux control (WB stage)
• V4 = ALUSrc mux control (EX stage)
• V5 = MemRead signal (MEM stage)
PARA-F. Assembly Loop Code:
The following code is executed on the 5-stage pipelined processor presented in class and similar to the one in the figure above. (Assume the initial content of $s2 is equal to 0x10000.) 
Loop: lw   $t0, 0($s0)       // $t0 = R8
      slt  $t1, $t0, $zero
      sb   $t1, 0($s1)
      addi $s0, $s0, 4       // $s0 = R16
      addi $s1, $s1, 1
      addi $s2, $s2, -1
      bne  $zero, $s2, Done
Done:
Recall that the forwarding selection is set to 10 when the dependency is on an instruction in the MEM stage, and to 01 when the dependency is on an instruction in the WB stage.
